# ¡Brum brum!

Jeux de voitures pour enfants de 3 ans (12 mini-jeux, espagnol / français, voix intégrées, fonctionne hors ligne).

## Obtenir l'APK
Chaque push sur `main` lance le workflow **Build APK** (onglet *Actions*). Ouvrir le dernier run réussi → section *Artifacts* → télécharger **BrumBrum-apk** (zip contenant `BrumBrum.apk`).

## Compiler en local
Ouvrir le dossier dans Android Studio, puis *Build → Build APK(s)*.

Le jeu lui-même est dans `app/src/main/assets/index.html`.
